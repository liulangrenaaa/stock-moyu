# stock-moyu

在 VS Code 底部状态栏查看股票行情，无需登录。支持上海、深圳、北京市场代码及相应指数。

## 使用

安装 VSIX 后，打开命令面板，执行 `Stock Moyu: 开启行情`。也可在编辑器正文区域右键，选择同名命令。

行情显示在底部状态栏左侧。点击行情文字，或执行 `Stock Moyu: 停止行情`，即可关闭。

在设置中搜索 `stockMoyu`，或在 `settings.json` 中配置：

```json
{
  "stockMoyu.stockCodes": ["sh000001", "sz002649"],
  "stockMoyu.updateInterval": 3000
}
```

- 股票代码需包含 `sh`、`sz` 或 `bj` 前缀，最多 50 个。
- 刷新间隔单位为毫秒，范围为 1000 到 3600000；每次请求结束后再等待该间隔。
- 运行中修改配置会立即生效。
- 请求失败会显示警告并自动重试；保留旧数据时会在悬浮提示中明确标注。
- 部分代码无有效行情时，其余行情仍可显示，缺失代码列在悬浮提示中。
- 默认不绑定快捷键，可自行给 `stockMoyu.start` 和 `stockMoyu.stop` 设置快捷键。

行情来自腾讯公开行情接口，显示值以接口响应为准。

## 开发

开发环境使用 Node.js 22 或以上版本、npm 和 VS Code 1.95 或以上版本。

```bash
npm ci
npm run check
npm test
npm run package
```

打包输出 `stock-moyu-0.1.0.vsix`，可在 VS Code 扩展面板中使用“从 VSIX 安装”。

在本目录打开 VS Code，按 F5 启动扩展开发宿主。在新窗口中执行开启行情命令即可调试。

运行时使用 VS Code API 和 Node.js 内置 HTTPS、字符解码功能，不依赖第三方抓取库。

## 已修复问题

- 重复开启创建多个定时器，停止后仍继续请求。
- 停止或切换配置后，旧请求结果覆盖新状态。
- 请求缺少明确的总时限，慢网络下轮询请求重叠。
- 空响应和无效代码检测失效，界面可能变成空白。
- 网络错误长期显示加载中，无法区分旧数据与新行情。
- 定时器、状态栏和配置监听器未完整释放。
- 配置名称和命令沿用原版，多个插件共存时存在冲突。
- 旧开发脚本依赖已缺失工具，安装包无法直接作为开发工程使用。

原安装包未提供许可证。本仓库保留来源说明，不将上游代码擅自标注为 MIT 或其他开源许可证；
